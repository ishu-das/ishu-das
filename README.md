# 💫 About Me:
I am a first-year Electronics and Communication Engineering (ECE) student passionate about the intersection of software development and hardware systems. Currently, I am building a strong foundation in C programming, Python, and Linux terminal environments, with a growing focus on microcontroller workflows and network tooling.<br>My primary interests lie in embedded systems, system-level scripting, and exploring Edge AI/TinyML applications on microcontrollers like the ESP32. I am eager to collaborate on open-source ECE projects, low-level software utilities, and practical engineering solutions. Feel free to connect or reach out regarding embedded software, Linux environments, or system-level configurations!
